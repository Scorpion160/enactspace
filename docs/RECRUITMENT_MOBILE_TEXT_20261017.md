# Recruitment form mobile text

Long questions and guidance wrap outside floating input decorations and remain visible while typing. Field controllers, keys, validation and the 1200-character limit are preserved. Selected dropdown values can be swiped horizontally; menu items wrap. Bottom navigation actions wrap at large text sizes.

Regression widgets cover all default questions and help at 320/360/390 pixels, normal and 200 percent text, both themes, before and after typing. A separate test checks horizontal scrolling of selected text. Existing flow tests scroll to dropdowns before tapping them.

Flutter is unavailable in the preparation environment. Run the guarded Windows sync script to analyze and execute tests before visual review. No build or production deployment performed.
